# Project BioGuard

## AI-Powered Livestock Biosecurity Platform

BioGuard is an AI-powered livestock biosecurity platform currently under development.

The current version focuses on **Foot-and-Mouth Disease (FMD)** as the first disease module. Future releases are planned to expand support to additional livestock diseases and incorporate AI-assisted outbreak analysis, workflow automation, and decision support.
